# Correspondence Analysis (AFC)

## Overview

This mini-project applies **Correspondence Analysis (AFC)**, also known as **Correspondence Analysis (CA)**, to study the relationship between eye colour and hair colour in a sample of 592 individuals.

The analysis was performed using Python in Google Colab.

## Objectives

- Construct and analyze a contingency table.
- Apply Correspondence Analysis to categorical data.
- Examine eigenvalues and explained inertia.
- Visualize row and column categories on a factorial map.
- Interpret the relationships between eye colour and hair colour.

## Dataset

The dataset contains 592 individuals.

- **Rows:** Eye colours (Brown, Hazel, Green, Blue).
- **Columns:** Hair colours (Brown, Dark, Red, Blond).
- **Data:** Number of individuals for each combination of eye colour and hair colour.

## Methodology

1. Create the contingency table.
2. Verify the total number of observations.
3. Apply Correspondence Analysis.
4. Examine eigenvalues and explained inertia.
5. Generate visualizations of the results.
6. Interpret the factorial map.
